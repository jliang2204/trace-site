A FEW THINGS TO KNOW

Keep it simple.

Is Trace free?

Yes. The current beta is free and ad-free, including recording, playback, event navigation, and clipping.

Does Trace upload my recordings?

Recordings are stored on your PC. Optional training-clip sharing requires an invite key and your opt-in; it automatically uploads selected short, audio-free clips. Clips may contain player names and chat. Diagnostic reports are uploaded only when you request it.

What do I need to run it?

A 64-bit Windows 10 or 11 PC. Capture and hardware encoding compatibility can vary by graphics card and driver. This beta is still being tested across hardware configurations; macOS and Linux are not supported.

How do updates work?

Trace checks for updates and shows an in-app banner. Select Update now to download and restart. An active recording is protected. If an older version is stuck waiting to update, use this page to download the latest installer directly.

Why might Windows show a warning?

The beta installer is not yet code-signed with a Windows publisher certificate, so Windows may show an unrecognized-app warning. Only download Trace from this page or its linked Trace update host.
